# LamdReady

LamdReady는 여행자 조건에 따라 전 세계 여행 규정을 검색·판정하는 여행 도우미입니다.

현재 단계: Blogger 1차 공개 홈 적용. https://landready.blogspot.com/ 에서 4개 목적지 공식 안내 연결·품목 안내·브라우저 체크리스트를 제공합니다. 실제 국가 규정 자동 판정 데이터는 아직 없습니다.

## 실행

Node.js 20 이상에서 `npm test`, `npm run check`를 실행합니다. 외부 의존성 설치는 필요하지 않습니다.

## 구현 범위

- 반입·면세·신고·허가·항공 운송 결과 분리
- AND/OR 조건과 조건 누락 처리
- 현지 사건 날짜 기준 적용 기간 검사 (종료일 제외)
- 미승인·출처 없는 규칙 제외
- 판정 축별 충돌 감지와 근거 추적
- 기본 릴리스 검증

테스트의 TEST 국가와 fixture-only 근거는 합성 자료입니다. 실제 여행 안내로 사용하지 않습니다.

## 남은 필수 작업

결과 enum/조건식의 완전한 스키마 검증, 구간·여행자 모델, 세관 합산 계산기, 실제 공식 근거 검수, 범위 중첩 충돌 검사, 릴리스 생성·게시, 판정 엔진과 공개 화면 연결.
