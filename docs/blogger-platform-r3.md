# LamdReady Blogger 플랫폼 전환 명세 R3

기준일: 2026-10-09.

## 적용 전 기준 스냅샷

- Blog ID: 5877919860330006636
- 현재 제목: LamdReady
- 공식 서비스명: LamdReady (화면·문서 공통). 패키지 식별자는 npm 규칙에 따라 lamdready.
- 공개 주소: https://ddori128.blogspot.com/
- 실제 관리자 설정과 공개 홈페이지를 읽기 전용으로 확인했습니다.
- 검색엔진 표시와 HTTPS 리디렉션은 활성화되어 있습니다.
- 검색 설명은 비활성화, 설정 시간대는 로스앤젤레스입니다.
- 공개 홈페이지에 기존 건강·영양 글과 관련 메뉴가 있습니다. 전체 콘텐츠 수는 조사하지 않았습니다.
- 테마·설정·게시물은 변경하지 않았습니다.

## 개발 방향

공개 화면은 Blogger XML 테마와 HTML/CSS/JavaScript로 구성합니다.
Next.js 앱을 Blogger 서버에서 실행하는 구조는 채택하지 않습니다.
기존 순수 JavaScript 판정 엔진과 fixture 테스트는 재사용합니다.
국가·품목 설명은 Blogger 글/페이지에 정적 HTML로 제공합니다.
개인화 판정은 고정 검색 페이지에서 브라우저가 수행합니다.
원본의 /ko/country/... URL은 Blogger 글/페이지의 실제 permalink에 맞춰 매핑합니다.
검색 결과 noindex 처리 방식은 테마와 실제 메타 출력으로 검증해야 합니다.

## 데이터 배포 결정

초기에는 승인 데이터만 생성하여 테마/페이지 내 정적 데이터 또는 외부 버전 JSON으로 제공할 수 있습니다.
저장량·테마 크기·공개 로딩 검증을 통해 한 방식을 확정합니다.
Cloudflare D1과 CDN은 공개 호스팅의 필수 요소에서 선택적 데이터 운영 수단으로 변경합니다.
외부 데이터 호스트를 쓰면 HTTPS, CORS, 릴리스 버전 일치, 장애 시 UNKNOWN 처리가 필요합니다.
Blogger에 관리자 자격증명·API key·D1 접근정보를 포함하지 않습니다.

## 전환 보호와 검증

기존 글의 삭제·비공개·리디렉션은 별도 범위 결정 전 수행하지 않습니다.
현재 테마와 콘텐츠를 백업하고 복원 경로를 확보한 후 적용합니다.
검토 가능한 테마를 준비하고 승인 범위 내 적용합니다.
저장 후 한 번 재로드하여 유지 여부를 확인합니다.
공개 홈·국가/품목 페이지·검색 기능을 PC와 모바일에서 검증합니다.
설정 시간대는 사이트 게시 시각용이며 규칙 적용 날짜는 구간 현지 날짜를 사용합니다.
검색 설명과 기존 건강 메뉴는 여행 서비스 전환 시 수정 후보입니다. 현재 미변경입니다.
