# LandReady 개발 고도화 실행명세 R2

기준일: 2026-10-09. 원본 Full Version R1의 제품 방향을 유지합니다.
플랫폼 변경: 사용자가 Blogger를 지정했습니다. 공개 화면·URL·배포에 관한 Next.js 항목은 [Blogger 전환 명세](blogger-platform-r3.md)가 우선합니다.
이 문서는 작업 범위를 구체화한 설계이며 외부 배포 승인이나 규정 검수 완료를 뜻하지 않습니다.

## 제품과 첫 출시

여행자 조건에 따른 입국 준비, 물품 판정, 공식 절차, 귀국 비교를 제공합니다.
전 세계 국가·지역을 표현할 구조와 실제 검증된 목적지 지원을 구분합니다.
초기 지원 목적지와 여권·관광 목적·교통수단 범위는 미확정입니다. 범위 확정 전 전 세계 SUPPORTED를 표시하지 않습니다.
회원, OCR, AI 채팅, 알림, 수익화, 정부 양식 대리 제출은 후순위입니다.

## 화면 흐름

1. 홈: 여권국가, 출발지, 목적지, 귀국지, 입국·귀국 날짜.
2. 여행 요약: 준비할 행동, 추가 질문, 미확인 항목.
3. 물품 목록: 품목·수량·단위·금액 입력과 해석 확인.
4. 결과: 반입, 면세, 신고, 검역·허가, 항공 운송을 분리.
5. 공식 절차: 공식 링크와 제출 기간, 체크리스트.
6. 귀국 비교: 별도 귀국 구간과 물품 목록으로 다시 판정.

‘면세 초과’를 ‘반입 금지’로 표현하지 않습니다. 조건 부족은 NEEDS_INPUT,
근거 부족은 UNVERIFIED, 충돌은 CONFLICT로 표시합니다.
EVALUATED는 적용 규칙을 찾았다는 의미이며 모든 축의 허용을 보장하지 않습니다.
여행일 미입력 시 현재 현지 날짜를 사용했다는 표시가 필요합니다.

## 내부 모델

- Traveler: 여권 발급국, 여권 종류, 거주국, 목적, 연령 기준일의 나이.
- TripLeg: 순번, 출발·도착 지역, 규정 관할, 도착 현지 날짜·시간대, 운송수단, 실제 입국 여부, 환승·재수속, 해외 체류시간.
- Item: 정규 품목, 수량과 단위, 가격·통화, 용량, 개봉 상태, 성분, 개인 사용 여부.
- Rule: 안정 ID, 버전, 관할, 품목, 적용 기간, 조건식, 분야별 결과, 검수 상태.
- Evidence: source ID, snapshot ID, 원문 위치, 적용 근거, 검토자·검토일.
- Release: schemaVersion, engineVersion, releaseId, 생성일, 데이터 해시.

국가 표시와 입국·세관 관할은 분리합니다. 규칙과 근거는 다대다로 연결합니다.
임의 JavaScript 규칙 실행은 사용하지 않습니다. 허용된 연산자만 평가합니다.
기본 엔진은 조건 매칭, 분야별 계산기는 세관 합산·조합·환산을 담당합니다.
금액은 부동소수점 합산을 피하고 통화별 최소 단위와 공식 환산 기준을 명시합니다.

## 게시·검수

원문 수집 → snapshot → 후보 → 검토 → 승인 → 고정 릴리스 → 검증 → 게시.
fetched_at, reviewed_at, verified_at, effective_from/to를 분리합니다.
수집 성공만으로 검증일을 갱신하지 않습니다.
초기에는 수동 공식 검수와 파일 기반 승인으로 시작할 수 있습니다.
충돌은 해당 관할·품목·조건·기간 범위의 후보 게시를 막습니다.
기존 승인 규칙도 잘못되었다는 근거가 있으면 경고·판정 중단 처리합니다.
내용 해시 변화만으로 규정 변경을 확정하지 않습니다.

## 배포 구조

D1은 승인된 규칙과 근거 메타데이터의 Master로 사용합니다.
RAW HTML/PDF 저장 위치·보존기간은 별도 확정하며 D1에 무제한 저장하지 않습니다.
Next.js 정적 페이지와 동일 릴리스의 JSON을 CDN으로 제공합니다.
개인화 검색은 고정 /check 페이지와 브라우저 판정으로 구성하며 noindex 처리합니다.
관리자 쓰기·오류 신고는 별도 인증 API가 필요합니다. 공개 번들에 자격증명을 넣지 않습니다.
HTML/JSON 버전을 맞추고 이전 릴리스 복구 경로를 둡니다.

## 단계와 완료조건

1. 기반: 판정 계약, 조건 매칭, 날짜·결측·충돌 회귀 검사.
2. 데이터: 초기 지원 범위 확정, 공식 원문 snapshot, 규칙 승인, 분야별 계산기.
3. 사용자 흐름: 여행 설정부터 공식 절차·귀국 비교까지 연결.
4. 출시: 승인 데이터 검산, PC·모바일 렌더링, 직접 URL·새로고침, 공개 실제 결과 확인.
5. 확장: 목적지별 coverage 승격, 자동 변경감지, 오프라인·알림.

법적 핵심 데이터의 미확인 값을 가짜로 채우지 않습니다.
SUPPORTED는 목적지와 검증된 여행자 범위·분야를 함께 표시합니다.
공식적으로 ‘없음’으로 확인된 규정은 결측과 구분합니다.

## 검증과 현재 상태

합성 fixture 회귀, 승인 실데이터 검산, Production/Manual Evidence를 별도 기록합니다.
현재 엔진은 기본 조건 매칭 구현이며 복합 면세 계산기와 완전한 게시 검증기는 미구현입니다.
초기 지원 범위 미확정은 실데이터 구축의 선행 결정이며 기반 구현을 막지 않습니다.
테스트 통과를 국가 규정 정확성 또는 서비스 운영 성공으로 보고하지 않습니다.
