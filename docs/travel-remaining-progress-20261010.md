코드 758df65 main push 후 자동 배포 c2b59622-aa8a-466b-9824-0fd823a9e979 확인. 배포된 화면의 공식 양식 가공 표시와 변경된 추천 목록 동작을 직접 확인했다. 수동 중복 배포는 하지 않았다.

## 변경과 검사

국가·도시 추천 option은 방향키로 선택하고 Tab 이동 대상에서 제외했다. Tab 입력 시 목록을 닫는다. 공식 양식 캡션에 LandReady의 번호·색상 가공 표시를 추가했다.

여행 전용 자동 점검 실행: `node scripts/audit-travel-current.mjs`. 최대 35요청, 동시 3개, 요청당 20초, 재시도 0회. 401/403/429 수신 후 새 요청을 중단하고 이미 시작된 요청 결과만 수집한다. 청크 완료 시 checkpoint 저장; 실패 후 자동 전체 재실행은 하지 않는다. 공개 HTML 점검은 숨겨진 테마 요소와 실제 노출을 구분해야 한다.

47개 테스트 PASS, 공개 자산 빌드와 267개 자산 검사 PASS. 신규 점검기의 noindex 검사는 HTML meta뿐 아니라 실제 응답 헤더를 읽도록 교정했다. 공급자별 과금 전체 한도나 모든 운영 기능 완료를 뜻하지 않는다.

## 공식 근거 확인

2026-10-10 [법무성 콘텐츠 이용 조건](https://www.moj.go.jp/hisho06_00280.html)에서 출처와 가공 표시 조건을 확인해 현재 양식에 적용했다. 특정 제3자 권리는 별도다.

[IndexNow 공식 문서](https://www.indexnow.org/documentation?hl=en)는 같은 호스트의 다른 keyLocation도 허용한다. 따라서 루트 경로 제한만으로 불가능하다고 판정하지 않는다. 현재 Blogger의 동일 호스트 UTF-8 키 파일 제공 경로가 확보되지 않아 미적용 상태를 유지한다. noindex 폼을 대체 색인 대상으로 변경하지 않았다.

## 원장과 남은 조건

C34/C40/C61 3개를 검증된 범위 적용으로 갱신했다. 총 95개 중 범위 적용 48개 / 미완료 45개 / 제외 2개다. 범위 적용은 후보 전체 운영 완료와 다르며 `runtimeVerified=false`는 전체 후보 검증 상태로 유지한다.

남은 실행은 여행 근거의 주장별 연결, 현재 탐색·자산 전체 검토, Bing 소유 확인, Google·네이버 수집 상태, 실제 분석 수신·검색/성능 표본이다. 공개 연락처 없음, 정기 일정과 홍보 채널 미지정은 해당 단계의 대기 조건으로 유지한다. 이전 건강글 본문 교정·삽화·관련 글 발행은 남은 작업에 포함하지 않는다.

후속 실행 후 현재 상태는 `travel-final-execution-20261010.md`를 기준으로 한다. 범위 적용77/대기16/제외2이며 위48/45는 당시 이력이다. 전체 최종 완료는 아니다.
