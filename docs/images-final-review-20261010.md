## 실행·복구 기준

`scripts/resume-images.mjs`는 기존 SEO 원장과 최초 이미지 원장의 확인 시각을 비교한다. 이어받기 원장이 다른 원장을 가리키면 `CHECKPOINT_MISMATCH_STOP` 오류로 중단한다. 기존 성공·실패 URL을 모두 제외하고 남은 이미지 URL만 요청한다.

요청은 동시 3개, 요청당 20초, 자동 재시도 없음이다. 각 3개 요청 묶음이 끝날 때 임시 파일 작성 후 rename으로 진행 상태를 저장한다. 실패가 발생해도 나머지 URL을 검사하며 이미 실패한 URL을 자동 재요청하지 않는다. 새 이미지 탐색·외부 링크 탐색은 수행하지 않았다.

수정 스크립트 구문 검사 PASS. 실제 공개 HTTP 응답 검사와 구문 검사는 별도 증거다. Blogger GUI 수정·배포·커밋은 이 작업에 포함하지 않았다.
