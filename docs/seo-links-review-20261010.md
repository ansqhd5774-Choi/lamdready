# 공개 SEO·외부 링크·이미지 점검 — 2026-10-10

- 기존 내부 링크 응답 313개와 홈에서 공개 22개 글로 이어지는 도달성 증거를 재사용했다. 같은 313개를 다시 요청하지 않았다.
- 공개 Blogger 게시글 피드 22/22개, 정적 페이지 피드 0/0개로 이번 목록의 완전성을 확인했다. 공개 홈과 글 22개, 합계 23개 문서의 서버 HTML을 검사했다.
- `artifacts/seo-links-audit.json`: 신규 요청 100개(피드 2개, 문서 23개, 외부 링크 75개). 동시 요청 3개, 요청당 20초, 재시도 없음. 검사 중 실패가 발생해도 나머지 대상을 계속 처리하고 요청 묶음마다 결과를 저장했다.
- `artifacts/image-response-audit.json`: 앞선 결과의 이미지 `src` 대상만 추출해 추가 50개 응답 검사. 기존 100개는 재요청하지 않았다. 동시 요청 3개, 요청당 20초, 재시도 없음.
- SEO 분석 함수 단위검사 2개 PASS, 신규 검사 스크립트 구문 검사 PASS. 테스트 통과와 실제 공개 응답 결과를 구분한다.

## 확인 결과

- 문서 23개 canonical 주소가 실제 요청 주소와 일치했다. 공개 홈·글에서 `noindex`는 발견되지 않았고 제목·본문 기반 soft 404 후보도 없었다. 이 결과는 검색엔진 수집·색인·노출 성공을 뜻하지 않는다.
- 글 22개에서 검색용 `meta name="description"`이 없었고 홈에서 `og:image`가 없었다. 기존 건강 글의 주장·본문을 자동으로 수정하지 않았다. 글별 설명 작성과 홈 대표 이미지 설정은 별도 보완 후보다.
- 검사한 23개 문서에서 **JSON-LD 스크립트가 탐지되지 않았다.** 이것은 구조화 데이터 전체가 없다는 뜻이 아니다. 현재 Blogger 테마 백업에는 `Blog`과 `BlogPosting`의 `itemscope`/`itemtype` **microdata가 존재한다.** 이번 검사 함수는 JSON-LD 스크립트 개수만 세었으며 microdata 유효성·검색엔진 처리 결과는 검증하지 않았다.
- HTML 이미지 태그 기준 alt 속성 누락 25개, width 또는 height 지정 누락 23개를 발견했다. 반복 UI 이미지가 포함된 문서별 합계이며 고유 이미지 수와 다르다. 이미지 내용·용도를 확인하지 않고 임의 alt를 생성하지 않았다.
- 추가 이미지 응답 검사 **50개 모두 HTTP 성공**, 조회 실패 0개다. 기존 이미지 후보 189개 중 **139개는 미검사**다. 이미지 픽셀 디코딩·실제 화면 로딩·이미지 권리는 이 응답 검사에 포함하지 않았다.

## 발견 오류와 수정 상태

최초 외부 링크 검사에서 이전 `ddori128.blogspot.com` 카테고리 경로 `Diet`, `Beauty`, `nutrient`, `Health`, `Food` 5개가 HTTP 404를 반환했다. 최소 수정안은 라벨·기존 디자인을 유지하고 카테고리 호스트만 현재 `landready.blogspot.com`으로 바꾸는 것이다.

이후 root 작업에서 카테고리 호스트 수정과 공개 홈·5개 카테고리, 합계 6개 URL의 HTTP 200 및 이전 링크 부재를 확인했다. 최초 오류 증거는 삭제하지 않고 유지한다. 본 점검 담당은 Blogger GUI 변경·배포·커밋을 실행하지 않았다.
