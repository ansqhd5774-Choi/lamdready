## 공통 적용 조건과 승인하지 않은 주장

S1은 외국인 입국 기록 양식이며 영어 또는 일본어로 기재하도록 안내한다. 현재 사이트는 그중 영문 준비를 돕는 범위다. 1–14 번호·예시 색상·복사·자동 변환은 자체 UX이며 공식 양식의 원래 번호나 필수 입력 UI가 아니다. 입국 목적·거주지·이력은 사용자가 실제 사실에 따라 고치는 정보이며 국가 경로 초기값이나 예시가 실제 사실을 대신하지 않는다.

S2는 온라인 입국·세관 절차 서비스라는 안내 근거다. S1의 종이 칸과 Visit Japan Web의 모든 화면·단계가 1:1로 같다는 주장은 검증하지 않았다. 본 사이트에서 결과를 복사하거나 공식 링크를 누른 것과 사용자 계정에서 신고를 제출하고 QR을 받은 것은 별도 결과다.

S3는 세관 휴대품 신고의 목적을 구분하는 근거다. 면세 한도·규제 약물·검역·비자 수치의 새로운 규칙을 구현하거나 규정 검증 상태를 true로 변경하지 않았다. 이 원문에서 검수한 설명만 범위를 한정해 재사용한다.
