# 현재 여행 사이트 실행 마감과 외부 대기

## 현재 실행 마감: 수동 운영 선택 반영

최신 원장 **범위 적용81 / 조건부 보류12 / 제외2**. C62/H32는 사용자 선택인 수동 운영으로 범위 적용했다. 예약 자동화를 만들거나 새 공개 점검을 실행한 것이 아니라, 이미 완료한 실제 점검 증거와 재현 가능한 한도·중단·복구 절차를 `docs/manual-review-runbook.md`에 연결했다. C45/H27의 잘못된 스트림 부재 메모도 실제 연결·수신·운영자 제외 상태로 수정했다. 장기 분석 표본 검증은 보류 상태를 유지했다.

조건부 보류12개는 C42/C43/C44/H29(검색 실적 표본), C45/H27(장기 집계 표본), C50/H28(외부 홍보 채널 미지정), C60(공개 연락처 없음이라는 사용자 선택), C35(이전 이름/서비스 폐기라는 사용자 선택), C51/H30(현재 여행 게시글0·검토 대상 없음)이다. 지금 반복 실행하면 완료되는 개발 목록이 아니다. 보류 조건이 달라질 때만 해당 지점에서 재개한다. 이12개를 모두 구현·운영 완료했다고 선언하지 않는다.

## 최신 원장: Bing 인증·제출 완료

2026-10-10 후속 실행에서 제공자 인증 방법 화면이 정상 표시됐다. 현재 실제 테마의 기존 msvalidate 태그와 제공자 태그가 일치해 테마 변경 없이 인증1회 성공. 등록 목록의 Not verified 표시 제거 및 LandReady 관리 진입 확인. 비어 있던 사이트맵 목록에서 `https://landready.blogspot.com/sitemap.xml` 1회 제출, Success 접수 알림/1행/Processing 확인. 수집·색인 성공은 미확인이다. 제공자 날짜 표시는10/9/2026이고 작업 날짜는 한국시간10/10이다.

C22/H13은 범위 적용으로 갱신했다. 최신 원장 **범위 적용79 / 대기14 / 제외2**. 아래77/16 및 Bing 오류 기록은 이전 상태다. 현재 정기 자동화 미생성은 사용자의 수동 점검 선택이다. 근거 `artifacts/bing-landready-submitted-20261010.png`, `data/search-status.json`.

## 후속 진행: 홈 분석 연결 완료

운영자 브라우저 제외 및 일반 방문 복구를 실제 요청으로 검증했다(각0/0/1건, 복구 응답204). 사용자가 정기 실행 없이 수동 점검을 선택했으므로 정기 예약은 만들지 않는다. 아래 C62/H32의 일정 미확정 기록은 이전 상태이며 현재는 수동 운영 선택이다. 검색 실적은 후속 확인에서도 처리 중이다.

사용자의 명시적 연결 승인 후 LandReady 전용 GA 속성/웹 스트림을 생성하고 실제 Blogger 홈에 연결했다. 향상된 자동 측정/광고 기능은 비활성, Worker 폼에는 태그를 추가하지 않았다. 공개 홈에서 페이지뷰 단일 요청 및 응답204, 제공자 실시간 활성 사용자1명 확인. 상세: `docs/analytics-setup-progress-20261010.md`. 아래의 분석 스트림 부재 및 홈 호출0 기록은 연결 전 상태다. C45/H27은 장기 집계·운영자 구분 검증이 남아 전체 완료로 바꾸지 않는다.

2026-10-10. **전체 95개 후보의 최종 완료는 아니다.** 현재 승인 범위에서 실행할 수 있는 개선을 마쳤으며, 적용 범위와 남은 조건을 분리한다. 원장: 범위 적용 77개 / 대기 16개 / 제외 2개. IMPLEMENTED_SCOPED는 해당 기준 전체의 영구 운영 성공을 뜻하지 않는다.

## 이번에 실제 마친 작업

1. 공식 양식 1~14번의 출처·적용 대상·변환 한계·불확실성·검수일 연결. 기존 공식 3개 원문 검수와 앞뒤 양식 증거를 재사용했다. 현재 선박명·출국명령·형사사건·현재 소지 문구와 이전 수정 후 Runtime 증거를 연결했다.
2. 일본 폼에 입국·세관 공식 안내를 접어서 표시. 실제 열린 화면에서 두 링크를 확인했고 홈→KR/JP→폼 이동 성공을 확인했다. 새 중복 글·허브 페이지를 발행하지 않았다.
3. 실제 Blogger 테마를 GUI에서 백업하고 홈에서 예전 블로그 위젯의 서버 출력을 제한했다. 번역·AdFit·페이지뷰 위젯과 건강 카테고리 DOM은 홈에 출력되지 않는다. Blogger가 기본으로 삽입하는 광고·플랫폼 스크립트는 별도이며 전부 제거했다고 주장하지 않는다.
4. 기존 GA 설정이 계정 번호를 측정 ID로 사용한 것을 실제 계정/스트림 화면과 대조했다. 해당 계정에는 다른 Tistory 웹 스트림만 확인됐다. 홈의 잘못된 analytics include를 제한하고 실제 DOM 및 새로고침 관찰에서 Google Analytics/Tag Manager 호출 0을 확인했다. 다른 사이트 스트림을 변경하거나 새 계정을 생성하지 않았다.
5. 공개 자산 점검에 JS/CSS 의존성·OG 이미지·치수·microdata를 추가했다. Blogger CSS escape를 가짜 내부 URL로 해석한 감사 도구 오류를 수정했다. 잘못 생성한 URL 6개의 404는 서비스 실패로 확대하지 않는다. 최종 현재 범위 20요청 성공, 공개 글·sitemap 글 URL 0, canonical/noindex/가공 표시 확인.
6. 고정된 채널/매체 쌍과 비개인 UTM으로 경로를 보존하는 생성기 구현. 여행 요약 1개만 유지하고 실제 외부 게시 0회를 유지했다.
7. 운영 기준의 공식 근거·확인일·자체 정책 구분·개정 기록 작성. 직접 읽은 문서와 기존 검수 재사용 및 공식 참고 링크를 구분했다.

- Blogger 테마는 별도 GUI 저장과 공개 Runtime으로 검증했다. Worker 배포가 Blogger 테마 저장을 대신하지 않는다. 재현 변환 스크립트: `scripts/gate-legacy-home.mjs`; 현재 테마 원본 백업이 필요하며 무조건 반복 적용하지 않는다.
- 현재 홈/폼 각각 320/360/390/768/1280px 가로 넘침 없음. 홈의 입력·이동 버튼 중심점에 다른 요소가 덮이지 않음. 320px 날짜 선택창 폭 273px로 화면 안에 표시.
- 공식 앞·뒷면 실제 디코딩: complete=true, 자연 크기1684×1191. 뒷면 lazy 유지. 기존 1~14입력·변환·복사·초기화·Tab 검증은 관련 기능 코드가 바뀌지 않아 재사용했다.
- 홈13/폼20응답 실제 브라우저 관찰. 단일 관찰이며 네트워크/CPU 표준 부하를 적용한 대표 성능 점수나 실사용 CWV로 해석하지 않는다. 폼 관찰 응답 오류0.
- 이미지 전체 권리 감사·실제200%브라우저확대·전체WCAG 인증은 미검증이며 이번 범위 PASS로 확대하지 않는다.

증거: `artifacts/travel-final-home-observation.json`, `travel-final-trip-observation.json`, `travel-final-home-layout.json`, `travel-final-layout-20261010.json`, `travel-current-audit.json`, `travel-final-home-proof.png`, `travel-final-source-proof.png`. 백업은 `backups/blogger-theme-before-travel-final-20261010.xml`, `blogger-theme-before-analytics-gate-20261010.xml`에 있으며 공개 저장소에 포함하지 않는다.
